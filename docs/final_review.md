## Key viva points
- Random Forest is used because it handles nonlinear relationships and mixed environmental features well.
- MAE is average absolute prediction error.
- RMSE penalizes larger errors more strongly.
- R² indicates explained variance relative to a baseline.
- Synthetic data is explicitly labelled and should not be described as real observations.
