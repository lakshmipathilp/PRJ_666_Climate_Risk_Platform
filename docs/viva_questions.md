# Likely Viva Questions

### Why AI?
To learn relationships between environmental variables and energy/risk outcomes and provide predictive decision support.

### Why Random Forest?
It captures nonlinear interactions and is robust for tabular data without requiring extensive feature scaling.

### What is Big Data in this project?
The system demonstrates processing of a large historical environmental dataset and is designed to scale toward chunked/distributed ingestion. The prototype remains laptop-friendly.

### How is cybersecurity used?
Passwords are bcrypt-hashed, API access uses JWT, inputs are validated, destructive actions require an admin role, and audit logs are stored.

### Why cloud computing?
The service is containerized and can be deployed to cloud compute/database services; local mode is retained for reliable academic demonstration.

### Why SDG 13?
The platform directly focuses on climate monitoring, impact assessment and environmental risk prediction.
